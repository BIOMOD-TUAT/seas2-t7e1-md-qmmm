# SEAS² Dry：T7E1 とバルジ DNA の MD・QM/MM 解析の研究記録

BIOMOD 2026 チーム TUAT のプロジェクト SEAS² のうち、計算（MD と QM/MM）の部分の記録です。
wiki の「MD / QM/MM」ページに載せた結果の、入力・解析の定義・結果の表・図の作成スクリプト・元データをまとめています。
QM/MM のモデルは MD の構造から作ったので、MD と QM/MM は分けずに 1 つのリポジトリにしています。

## フォルダ

- `01_model_building/`：複合体モデルの作り方（分かっている手順と、記録がない手順）
- `02_md/`：MD の入力（追加予定）、解析の定義、結果の表
- `03_qmmm/`：QM/MM の入力（追加予定）、部分ヘシアンの計算ツール、結果の表、構造
- `04_figures/`：図の作成スクリプト、ChimeraX と VMD のファイル（図・PowerPoint・元データはチームの Google Drive にあります）
- `docs/`：方法の要約、限界、やることの一覧

## 使うときの注意

- QM/MM の障壁（ΔE‡ = +57.6 kcal/mol、ΔG‡ = +52.7 kcal/mol）は、酵素反応として現実的な値よりはるかに高く、安定な生成物も得られていません。実際の反応を定量的に再現した結果ではありません。
- MD の 0A〜5A の比較は各条件 1 本の計算で、初期構造や作り方がそろっていません。バルジ長の優劣は結論できません。
- 詳しくは `docs/limitations.md` を見てください。
